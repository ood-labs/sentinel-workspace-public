# Scientific Organism

Scientific Organism is a 1280x720, Features-driven Sentinel performance
instrument. It was authored live as a visible semantic chain: every custom node
has its own inspectable preview, and every downstream structure is derived from
real state rather than decorative telemetry.

## Signal chain

1. **Scientific Seed Lab** — persistent Canvas editor for painting, selecting,
   moving, and clearing stimulus records.
2. **Scientific Biotic Source** — an intentional living-field generator driven
   by those records.
3. **Scientific Analysis Proxy** — a 480x270 source-derived aperture branch
   dedicated to analysis.
4. **Scientific Features** — Sentinel's real model-free Features node, bounded
   to blobs, corners, and lines.
5. **Scientific Feature Temporalizer** — converts detections into 96 stable
   64-byte agents with velocity, age, confidence, kind, and source identity.
6. **Scientific Topology Weaver** — publishes 96 confidence-weighted 48-byte
   edge records.
7. **Scientific Synaptic Field** — renders the measured agents and edges as a
   live vector/energy field.
8. **Scientific Organism Renderer** — canonical data-driven Program renderer
   with Performance and Hero modes.
9. **Scientific Filament Memory** — persistent temporal trails.
10. **Scientific Relief Chamber** — directional etched relief.
11. **Scientific Spectral Archive** — restrained multi-time spectral memory.
12. **Scientific Signal Glyphs** — real blob bounds, stable-ID bits, corner
    orientation, line endpoints, and animated edge-phase probes.
13. **Scientific Final Grade** — black-floor, highlight-rolloff, grain, and
    registration finish.
14. **Scientific Performance Deck** — full-bleed performance Canvas.
15. **Scientific Organism Output** — Scene Group endpoint for the final Program.

## Performance interfaces

Open **Scientific Performance Deck** for the stage-fitted Program preview and
three direct-manipulation macro pads:

- Energy controls synaptic energy and field warp.
- Structure controls topology and relief.
- Memory controls filament persistence and spectral archive.

The preset buttons and keyboard equivalents are:

- `Q` — Observe
- `W` — Surge
- `E` — Archive
- `R` — Balanced

The Deck publishes structured performance records and scalar control outputs.
Live expressions drive the downstream nodes every frame. The Deck does not
duplicate ordinary Properties sliders.

Open **Scientific Seed Lab** to edit the source stimuli. Its Canvas follows the
actual panel extent while preserving an aspect-correct 16:9 stage, so pointer
coordinates and normalized Stimuli records remain aligned at any dock size.
Click to add, drag a stimulus to move it, use the wheel during that drag to
change only its radius, and use Alt+wheel during the drag to change only its
strength. Radius is visible in the ring; strength is visible in the core and
halo intensity.

The **SCIENTIFIC ORGANISM / LIVE INSTRUMENT** Scene Group exposes only seven
high-impact shaping controls: Corner Reach, Agent Radius, Edge Radius, Light
Direction, Print Contrast, Ink Saturation, and Micro Detail.
