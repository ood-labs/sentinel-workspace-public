# Dancer source clip

`dancer_vert.mp4` is the shared 24.76-second, 512x896 H.264 dancer source used by the tracking and analysis studies. It was copied byte-for-byte from `projects/streamdiff_workflows/assets/dancer_vert.mp4` in this repository. Both files have SHA256 `4B7F7AE1C87F28734165872231C1ABF0AA719AD6CB9CCBE340912858690C6A56`.

The source repository distributes this asset with the example collection under the repository's MIT license. The file remains in one shared `videos/` folder so every saved project resolves the same portable relative path.

Before a public Sentinel release promotes this collection, the project owner will choose the timing for any final dancer-clip swap. A replacement must have redistribution rights, preserve a useful portrait dance performance with visible hands, and be revalidated across studies 01 through 09 and 18. Update the hash and provenance here when that swap occurs.
