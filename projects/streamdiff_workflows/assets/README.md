# Motion guide asset

`dancer_vert.mp4` is the dancer source used for the Video Depth Control study. It is a 24.76-second, 512x896 H.264 clip at 25 fps and is bundled so the Marble Dancer graph remains portable. Replace it with another portrait motion clip to test how depth structure changes the generated marble figure.

The asset contains no downloaded footage, audio, model weights, or third-party media.
